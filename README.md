# UrlChart MCP

This repository exists to register the UrlChart MCP server with the Official MCP Registry ([registry.modelcontextprotocol.io](https://registry.modelcontextprotocol.io)). The `server.json` here declares the streamable-HTTP remote at <https://urlchart.craftstead.app/mcp>, which renders charts as PNG images from a URL using a Google Image Charts / Image-Charts compatible API. Documentation for the MCP server is at <https://urlchart.craftstead.app/mcp-server/>, and the full product (parameter reference, tester, pricing) lives at <https://urlchart.craftstead.app/>.
